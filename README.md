# Krishna Prasad Kurmi — Personal Portfolio

A responsive personal portfolio website for Krishna Prasad Kurmi, a Computer Science and Engineering student exploring backend development, C++, Data Structures and Algorithms, and MongoDB-backed project work.

## Built With

- HTML
- CSS
- Vanilla JavaScript

No framework, build step, or backend service is required.

## Website Sections

- Hero and profile introduction
- About Me
- Skills and Technologies
- Featured Projects
- Project filters and accessible project details modal
- Achievements and Learning Journey
- Contact information and front-end-only contact form
- Social links and responsive footer

## Run Locally

1. Open the project folder in VS Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The site can also be opened directly in a browser, but Live Server provides the most convenient local development workflow.

## GitHub Pages Deployment

1. Create a new GitHub repository, or select an existing repository for this portfolio.
2. Place `index.html`, `style.css`, `script.js`, `profile-photo.png`, and this `README.md` in the repository root.
3. Confirm that `index.html` is directly at the root level, not inside another folder.
4. Commit and push the files to the `main` branch using Git or upload them through GitHub.
5. Open the repository's **Settings**.
6. Select **Pages** in the sidebar.
7. Under the deployment source, choose **Deploy from a branch**.
8. Select the `main` branch and the `/ (root)` folder if available.
9. Click **Save**.
10. Wait for GitHub Pages to finish deploying.
11. Open the generated Pages URL and test the website and its assets.

The published URL depends on the GitHub account name and repository name. Do not assume a URL until GitHub displays it.
